# Tool icon sources

The seven brand glyphs come from [Simple Icons](https://github.com/simple-icons/simple-icons), distributed under [CC0 1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md). Brand names and trademarks belong to their respective owners.

The profile uses the original glyph geometry in custom labeled tiles, with monochrome light and dark palettes and an orange accent. Each tile is self-contained and served from this repository.
